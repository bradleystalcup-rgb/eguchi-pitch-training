# Eguchi/CIM Protocol Notes

This app is inspired by the Eguchi Chord Identification Method as summarized in
Sakakibara's longitudinal report. It should not claim guaranteed perfect pitch.

## V1 Training Defaults

- Parent-managed practice for children.
- Four to five short sessions per day during active learning.
- Twenty trials per session by default, targeting two to five minutes.
- Add new chords no sooner than two weeks after the previous addition.
- Advance only after perfect identification of the current active chord set.

## Chord Sequence

The first phase uses nine white-key color chords:

1. Red: C E G
2. Yellow: C F A
3. Blue: B D G
4. Black: A C F
5. Green: D G B
6. Orange: E G C
7. Purple: F A C
8. Pink: G B D
9. Brown: G C E

After the nine white-key chords are mastered, v1 adds five black-key major
chords by tone name for a 14-chord essential set.
